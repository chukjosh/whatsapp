# WhatsApp Chat Mobile App

## About

A Flutter UI clone inspired by WhatsApp, an instant messaging and VoIP service by meta. The goal of this project was to replicate a sample WhatsApp interface.

---

## Getting Started

**Clone the repository:**
```bash
git clone https://github.com/chukjosh/whatsapp
```

**Navigate to the project directory:**
```bash
cd whatsapp
```

**Install dependencies:**
```bash
flutter packages get
```

**Run the app:**
```bash
flutter run
```
