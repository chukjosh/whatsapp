# WhatsApp Chat Mobile App 💬

## About 📖

A Flutter UI clone inspired by WhatsApp — a free, cross-platform instant messaging and VoIP service. The goal of this project was to replicate the familiar WhatsApp interface as closely as possible. Hope you like it! 🔥

---

## Challenges & Learnings 🤯

During development, I picked up a lot about app logic, folder structure, and Flutter widgets. Overall, the process went smoothly — though one small mistake cost me a fair amount of time. The fix turned out to be as simple as running `flutter pub get` in the terminal. Once I figured that out, everything worked correctly on Flutter v3.0.5.

---

## Getting Started 🚀

**Clone the repository:**
```bash
git clone https://github.com/chukjosh/Whatsapp
```

**Navigate to the project directory:**
```bash
cd Whatsapp
```

**Install dependencies:**
```bash
flutter packages get
```

**Run the app:**
```bash
flutter run
```
